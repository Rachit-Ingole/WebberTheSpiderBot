# Known people gallery

Create one folder per authorized person and place a few clear face photos in it:

```text
known_people/
  rachit/
    front.jpg
    side.jpg
  mom/
    front.jpg
    side.jpg
```

Use different angles and lighting where possible. Keep one person per image,
with the face reasonably clear and unobstructed. The folder name becomes the
person's identity label.
